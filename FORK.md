# OpenClaw fork for ai-workbench

Branch `aiwb/2026.10.10`, based on the `v2026.10.10` release. Package builds and installation are
handled by [ai-workbench](https://github.com/SingularBunny/ai-workbench) (`WORKBENCH_OPENCLAW_PACKAGE`). The package is built by the
`aiwb package` workflow (`.github/workflows/aiwb-package.yml`) on GitHub-hosted runners with signed build provenance;
an `aiwb-*` tag publishes it as a release. Check a downloaded package with
`gh attestation verify <file>.tgz -R SingularBunny/openclaw`. A local build: `tools/openclaw-fork-build.sh` in ai-workbench. Without the settings below the fork behaves as upstream. **Models**: "any model" — the change works whatever model the agent runs on; "Claude CLI only" — it needs the `claude-cli` backend (Claude Code).
